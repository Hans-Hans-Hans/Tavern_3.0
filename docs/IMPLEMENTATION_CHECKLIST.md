# Tavern implementation checklist

This maps the supplied 130-section product brief to the current working tree. It is a source and test inventory, not a claim of complete Discord/Slack/Teams parity or completed production acceptance. The existing Matrix architecture and working behavior were extended rather than replaced.

**Present** means the main requested behavior has a concrete implementation. **Partial** identifies remaining requested behavior. **Gate** requires live deployment, interoperability, performance, or usability verification. **Optional** identifies an explicitly optional capability that is not implemented. These labels do not turn a passing unit test into a live service test.

Evidence was updated on 2026-09-09. Changes after this review should update the corresponding rows. The current implementation is distributed across the browser, the authenticated account API, Synapse authorization modules, and the optional operations/integrations services.
